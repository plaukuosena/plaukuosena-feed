Sveiki,

Man reikia kuo labiau automatizuoti produktų feed'ą Kaina24 integracijai.

Prašau padėti įdiegti arba patikrinti šį sprendimą:

1. Sistema turi automatiškai nuskaityti https://plaukuosena.lt/sitemap.xml
2. Iš sitemap atrinkti produktų puslapius.
3. Iš kiekvieno produkto puslapio nuskaityti Product structured data / JSON-LD:
   - produkto pavadinimą
   - kainą
   - valiutą
   - produkto URL
   - nuotrauką
   - brandą
   - prieinamumą
4. Pagal taisykles sugeneruoti SKU.
5. Sugeneruoti Kaina24 tinkamą XML feed.
6. Feed turi automatiškai atsinaujinti bent 1 kartą per dieną.
7. Ideali galutinė XML nuoroda: https://plaukuosena.lt/kaina24.xml

Svarbu:
- Jeigu produkto kaina keičiasi puslapyje, XML feed turi atsinaujinti automatiškai.
- Nuolaidos kodų į feed perduoti nereikia, nes Kaina24 paprastai mato tik produkto kainą.
- Jeigu Hostinger neleidžia laikyti dinaminio XML, galima naudoti išorinį sprendimą: GitHub Actions / server cron / Google Cloud / kitą paprastą automatizaciją.

Pridedu failus:
- generate_feed.py
- config.json
- requirements.txt
- GitHub Actions workflow
- README

Prašau patikrinti, ar galima šį generatorių paleisti taip, kad Kaina24 turėtų viešą nuolat atsinaujinančią XML nuorodą.
